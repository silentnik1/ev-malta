Підключення Google Drive

Потрібен Google OAuth Client ID для синхронізації між пристроями.

Кроки:
1. console.cloud.google.com → New project "EV Malta"
2. APIs → Google Drive API → Enable
3. OAuth consent screen → External
4. Credentials → OAuth 2.0 Client ID → Web app
5. Authorized JS origins: null
6. Скопіюй Client ID нижче
